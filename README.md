 Esta web, es una web personal con estética retro de videojuego, pixel-art y efectos de neón. Presenta información sobre Joan, sus intereses, sus objetivos y sus proyectos mediante una experiencia interactiva y visual.
✨ Características
- Portada arcade con accesos a las diferentes secciones.
- Conóceme, con presentación personal, aficiones, datos y metas.
- Índice interactivo 3D para explorar los temas del diario.
- El bar, una sección temática con una ambientación propia.
- Herramientas y APIs, con utilidades como el conversor de divisas, información de países y tiempo.
- Juegos arcade en Herramientas: Snake, Buscaminas y Comecocos.
- Modo claro y oscuro.
- Diseño adaptable a ordenadores, tabletas y móviles.
- Animaciones, efectos luminosos y transiciones visuales.
Las funciones disponibles pueden variar según la versión de los archivos instalada.
🧰 Tecnologías
- HTML5 para la estructura.
- CSS3 para el diseño, los colores, las animaciones y la adaptación a diferentes pantallas.
- JavaScript para la navegación, las interacciones, los juegos y las herramientas.
- APIs externas para algunas utilidades que necesitan datos actualizados.
📁 Estructura del proyecto
Los nombres exactos pueden variar según la versión. Una estructura habitual es:
  mi_web6/
├── index.html
├── styles.css
├── script.js
├── extras.js
└── img/
    └── imágenes y recursos visuales
- index.html: contenido y estructura de la web.
- styles.css: estilos visuales y diseño adaptable.
- script.js: navegación y funcionalidades principales.
- extras.js: código adicional, como los juegos arcade, si está enlazado desde el HTML.
- img/: imágenes y recursos gráficos.
Importante: conserva juntos los archivos que se enlazan entre sí y mantén las rutas de las imágenes. Si tu proyecto utiliza otros nombres, refleja los nombres reales de tu carpeta.
🚀 Cómo ejecutar la web
1. Descarga o clona el repositorio.
2. Abre la carpeta del proyecto.
3. Abre index.html en un navegador para probar la web.
4. Si alguna función depende de una API externa, comprueba que haya conexión a Internet y revisa la configuración correspondiente si no carga.
Para trabajar cómodamente, puedes abrir la carpeta en un editor de código y utilizar un servidor local, por ejemplo, Live Server.
🕹️ Navegación y uso
Explora las secciones desde los accesos de la web. En el índice 3D puedes utilizar sus controles de navegación y, cuando estén disponibles, el ratón, las flechas del teclado o los gestos táctiles. Los juegos incluyen sus propios controles e instrucciones.
🎨 Identidad visual
Esta web combina fondos oscuros, tonos azules, naranjas y dorados, bordes luminosos y detalles inspirados en los videojuegos clásicos. El objetivo es mantener una identidad retro reconocible con una presentación clara y adaptable.
